# 🚀 SkillVibe Backend

Backend desarrollado para la plataforma **SkillVibe**, una aplicación orientada a la gestión de habilidades, usuarios y procesos digitales mediante una arquitectura moderna basada en Spring Boot.

---

# 📌 Descripción del Proyecto

SkillVibe Backend proporciona una API REST robusta y escalable encargada de la lógica de negocio, validaciones, persistencia de datos y comunicación con la base de datos.

El proyecto fue desarrollado siguiendo buenas prácticas de organización y separación de responsabilidades para garantizar mantenibilidad y escalabilidad.

---

# 🛠️ Tecnologías Utilizadas

* Java
* Spring Boot
* Maven
* MySQL
* JPA / Hibernate
* REST API

# 🔧 Instalación y Ejecución

## 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/MiguelSantacruz1/skillvibe-backend.git
```

## 2️⃣ Ingresar al proyecto

```bash
cd skillvibe-backend
```

## 3️⃣ Ejecutar la aplicación

```bash
mvn spring-boot:run
```
